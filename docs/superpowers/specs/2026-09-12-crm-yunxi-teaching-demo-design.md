# CRM 与联通云犀独立教学演示系统设计规格

日期：2026-09-12  
状态：修订版，待用户确认后进入实施计划

## 1. 目标与边界

把现有单页 CRM 原型优化为两个互相独立的课堂演示区域：

1. CRM 教学区：突出线索发现、线索公海、领取分配、联系客户、跟进、客户转化和商机推进。
2. 联通云犀教学区：独立演示云名片、呼叫控制、AI 数析、AI 助手、AI 助销五项产品能力。

本项目不演示 CRM 与云犀的数据协同、接口回写或组合方案，不涉及 aTrust、DNS、代理、VPN 或远程访问方案。

系统继续使用纯静态单页、浏览器 localStorage 和 GitHub Pages。所有企业、联系人、电话号码、通话、预算、评分和操作结果均为教学模拟，不连接真实电话或业务平台。

## 2. 产品资料依据与准确口径

方案依据金山文档中的以下资料整理：

- 《天津河东联通——云犀营销实战课程——封号与号码标记增补 106 页》
- 《附件1：联通云犀·AI云犀助手产品介绍——2026.3.30》
- 《联通云犀·AI助销产品介绍——2026年5月》
- 《云犀功能体验（数析+助销）》
- 《联通云犀云应用标准资费表（全国）》

项目全文统一使用产品关键词“AI 数析”，不使用“AI 数悉”。

### 2.1 云名片

定位：工作手机的企业品牌窗口，解决陌生号码身份辨识问题。

演示口径：

- 展示静态版与动态版的教学差异。
- 模拟客户手机收到企业身份亮显或运营商消息。
- 展示企业名称、服务类型、来电目的和显示预览。
- 明确不同终端、运营商、行业准入和实际配置可能影响展示效果。
- 不承诺所有终端均显示，不宣传清除号码标记或规避监管。

### 2.2 呼叫控制

定位：工作手机的呼叫行为管家，用于规范企业外呼服务。

演示口径：

- 配置单号码周期内联系次数。
- 配置员工周期内外呼额度。
- 配置允许外呼时段。
- 配置禁止拨打的黑名单。
- 展示控制策略详情和呼叫控制记录。
- 模拟命中规则后的限制提示及原因。

产品价值聚焦授权、合规、有序触达和减少重复打扰，不描述为“保证不封号”。

### 2.3 AI 数析

定位：360° 解读企业通话内容的 AI 通话分析助手，面向企业管理与经营分析。

演示口径：

- 建立行业分析模型或 Agent。
- 选择需要分析的数据标签。
- 模拟对通话录音进行转写、分类和结构化标注。
- 输出客户意向、预算、需求、问题是否解决、满意度、员工评价等结果。
- 展示客户画像、高价值线索、问题清单、通话评分和汇总报告。
- 支持从图表或标签下钻到模拟通话及转写内容。

AI 数析重点是“一段时间内、多员工、多通电话”的管理分析，不把它画成通话中的实时话术助手。

### 2.4 AI 助手

产品名称显示为“AI 助手”，副标题可注明“AI 云犀助手／原 AI 云助理个人版”。

定位：智能处理个人工作通话的 AI 商务助手。

演示口径：

- 历史通话列表与详情。
- 录音播放和角色区分转写。
- 自动生成通话纪要及待办事项。
- 基于指定通话进行 AI 对话，例如生成跟进清单、营销报告或回复建议。
- 演示通话速记、现场速记和本地音频速记三种入口，但只将通话速记设为主流程。
- 模拟微信小程序界面，以移动端卡片形式呈现。

AI 助手服务个人信息整理，不等同于 AI 数析的企业经营分析，也不等同于 AI 助销的通话中实时推荐。

### 2.5 AI 助销

定位：营销服务场景中的实时 AI 话术推荐官，主要面向呼出营销场景。

演示口径：

- 企业知识库：上传产品资料、配置 QA 话术和高频问题。
- 通话前：显示客户历史联系次数、最近沟通与已有标签。
- 通话中：模拟实时转写、知识库匹配、话术推荐、异议处理和客户标签触发。
- 通话后：生成通话小结、客户意向、跟进策略和完整通话记录。
- 管理者可回看录音、转写、话术触发过程和客户标签。

课堂演示采用汽车 4S 店销售邀约场景：潜客提出价格、置换和试驾时间异议，AI 助销根据知识库实时推荐应答。

## 3. CRM 信息架构

### 3.1 导航优先级

CRM 默认首页改为“线索作战台”，一级导航按以下顺序排列：

1. 线索作战台
2. 天津河东客户公海
3. 我的线索
4. 线索分配与回收
5. 联系客户
6. 跟进任务
7. 客户与商机
8. 成交管理
9. 经营分析

云犀教学区位于 CRM 导航下方的独立分组，包含：

1. 云犀演示首页
2. 云名片
3. 呼叫控制
4. AI 数析
5. AI 助手
6. AI 助销

云犀分组使用不同色带和“产品教学模拟”标识，避免与 CRM 功能混淆。

### 3.2 模块精简

- 联系人并入客户画像。
- 电话工作台、通话记录合并为“联系客户”。
- 任务日历、外勤拜访合并为“跟进任务”。
- 客户管理、商机看板合并为“客户与商机”。
- 产品报价、合同、订单、回款合并为“成交管理”。
- 录音转写和通话质检不再作为 CRM 一级页面，只在联系记录详情中展示必要结果。
- 删除只弹出“操作完成”但没有业务状态变化的占位按钮。

## 4. 天津河东客户公海

### 4.1 数据规模与性质

新增 50 家天津市河东区教学模拟企业。企业名称采用明显的模拟名称，不冒充真实注册主体，也不提供外部工商来源链接。

页面顶部统一显示：

> 本页企业、联系人、号码、经营情况、需求与评分均为课堂模拟，不代表真实企业信息或真实销售机会。

### 4.2 行业组成

50 家企业按高频客户联系场景分布：

| 行业类型 | 数量 | 典型联系场景 |
| --- | ---: | --- |
| 健身房与运动场馆 | 8 | 体验课邀约、会籍续费、私教回访 |
| 美容、美发与医美服务 | 8 | 到店预约、疗程回访、会员复购 |
| 汽车 4S 店及汽车服务 | 8 | 试驾邀约、报价跟进、保养续保 |
| 教育培训机构 | 8 | 试听邀约、课程咨询、续费回访 |
| 家装、家居与房产服务 | 6 | 量房预约、方案确认、到店邀约 |
| 财税、法律与企业服务 | 5 | 资料催办、续约提醒、客户咨询 |
| 口腔、体检与养老服务 | 4 | 预约提醒、服务回访、健康咨询 |
| 电商、物流与本地配送 | 3 | 配送联系、售后确认、会员运营 |
| 合计 | 50 |  |

以上行业分布用于 CRM 公海教学，不代表云名片等具体产品一定准入。云犀产品页面另行提示行业准入和实际办理需核验。

### 4.3 地域分布

模拟企业分布在河东区常见片区及街道标签：大王庄、大直沽、中山门、富民路、春华、唐家口、常州道、上杭路、东新、鲁山道、二号桥、向阳楼。

这些地域只用于课堂筛选和客户池分组，不声称企业真实注册或经营于该地址。

### 4.4 数据字段

每家模拟企业包含：

- 企业名称
- 行业及细分业态
- 河东区片区/街道
- 门店或团队规模
- 模拟联系人及脱敏号码
- 线索来源：商圈走访、公开地图、异业推荐、活动名单、存量客户转介绍等模拟来源
- 最近联系情况
- 当前状态：待领取、待首呼、已联系、需跟进、公海沉睡
- 线索评分和优先级
- 预计需求、预算区间和推荐跟进动作
- 公海剩余保护期和回收原因

### 4.5 公海交互

- 按行业、街道、规模、线索评分、状态、来源和保护期筛选。
- 支持关键词搜索和排序。
- 支持单条领取、批量领取、分配给客户经理。
- 领取后从公海移入“我的线索”。
- 模拟超时回收和退回公海，保留历史领取及跟进记录。
- 支持查重，按企业名称、脱敏号码和门店名称识别模拟重复项。
- 每条线索可直接查看画像、模拟拨打、创建跟进任务和转为客户。
- 首页展示行业分布、街道分布、待领取数、高分线索数和今日新增数。

## 5. CRM 联系客户流程

CRM 联系客户页继续模拟通用 CRM 能力，不出现云犀产品名称：

1. 从公海或我的线索选择企业。
2. 模拟拨号并显示客户画像。
3. 记录是否接通、沟通结果、需求和异议。
4. 创建下次联系时间和任务。
5. 更新线索评分及状态。
6. 满足条件后转为客户和商机。

通话记录详情可以展示模拟录音、转写和质检结果，但不解释其技术来源，也不与云犀建立数据连接。

## 6. 云犀五项独立功能演示

### 6.1 演示首页

首页只展示五张产品卡：云名片、呼叫控制、AI 数析、AI 助手、AI 助销。

每张卡固定包含：

- 客户问题
- 产品定位
- 三项核心能力
- 适用场景
- “进入操作演示”按钮

### 6.2 云名片操作演示

选择静态版或动态版 → 填写模拟企业身份 → 选择外呼场景 → 预览客户手机显示 → 切换不同终端条件 → 查看边界说明。

### 6.3 呼叫控制操作演示

选择员工号码 → 设置频次、额度、时段、黑名单 → 保存策略 → 模拟合规拨打 → 模拟违规拨打 → 查看呼叫控制记录。

### 6.4 AI 数析操作演示

选择汽车、教育、美容或企业服务行业模型 → 勾选分析标签 → 启动批量分析 → 查看经营看板 → 下钻高意向客户、客户问题和员工评价 → 打开录音转写详情。

### 6.5 AI 助手操作演示

打开模拟手机端 → 选择通话记录 → 播放录音/查看转写 → 一键生成纪要和待办 → 向 AI 询问“下一步应该如何跟进” → 查看生成结果。

### 6.6 AI 助销操作演示

选择 4S 店知识库 → 选择潜客 → 发起模拟呼出 → 实时转写 → 客户提出价格、置换或试驾异议 → 系统推荐话术 → 触发客户标签 → 挂断 → 生成通话小结和跟进策略。

## 7. 自动演示

顶部“自动演示”改为两个互相独立的入口：

### 7.1 CRM 线索流程

进入天津河东客户公海 → 筛选汽车 4S 店 → 领取高分线索 → 模拟首次联系 → 创建 T+2 跟进 → 转为客户及商机 → 推进至成交。

### 7.2 云犀产品功能巡演

依次演示：

1. 云名片身份亮显
2. 呼叫控制策略配置及拦截
3. AI 数析批量标签分析
4. AI 助手生成纪要和待办
5. AI 助销实时话术推荐及话后小结

两条演示不共享业务数据，也不展示接口连接。均保留播放、暂停、上一步、下一步、倍速、重播和退出。

## 8. 状态、异常与隐私

- CRM 数据与云犀演示数据使用两个独立 localStorage 命名空间。
- 自动演示前分别保存各自快照，退出时只恢复对应区域数据。
- 所有电话号码保持脱敏，所有企业和人物标注为教学模拟。
- 云名片显示失败时展示终端/运营商条件提示。
- 呼叫控制策略冲突时显示具体规则，不执行拨打。
- AI 数析分析失败时保留任务并允许重试。
- AI 助手生成失败时保留原录音及转写。
- AI 助销知识库未配置时不推荐话术，并提示先选择知识库。
- 一键重置可分别重置 CRM 数据或云犀演示数据。

## 9. 实施范围

本轮包括：

- 调整 CRM 导航和默认首页。
- 新增 50 家天津河东区教学模拟企业及公海交互。
- 精简 CRM 一级模块并强化线索联系主流程。
- 新增五项独立云犀产品操作演示。
- 新增 CRM、云犀两条独立自动演示路线。
- 统一“AI 数析”等产品关键词与能力边界。
- 更新 README、教学说明和数据免责声明。
- 完成桌面、笔记本、窄屏测试并发布到现有 GitHub Pages。

本轮不包括：

- CRM 与云犀协同、接口回写或组合方案。
- aTrust、DNS、代理、VPN、虚拟机或远程访问建议。
- 云犀其他产品及云录音、云转写、云质检的独立产品页面。
- 真实电话、真实 CRM、真实云犀或任何外部 API 接入。
- 真实天津河东企业工商数据、个人联系方式或真实销售机会。

## 10. 验收标准

- 打开系统后第一屏为线索作战台，线索相关功能优先于报表和交易模块。
- 天津河东客户公海恰好包含 50 家明确标注的教学模拟企业，行业数量符合规格。
- 公海筛选、搜索、排序、领取、分配、回收、查重、拨打和客户转化可用。
- 领取后公海与我的线索数量同步变化，刷新后保留。
- CRM 一级导航完成合并精简，客户、商机、成交数据仍可访问。
- 云犀区只包含云名片、呼叫控制、AI 数析、AI 助手和 AI 助销五项产品入口。
- 五项产品均具有可点击、可改变界面状态的操作演示，不是静态介绍卡。
- AI 数析、AI 助手、AI 助销的定位及交互不存在混用。
- CRM 与云犀不共享数据，不出现“协同、回写 CRM、联动 CRM”等演示。
- 页面不包含 aTrust、DNS、代理、VPN 或远程访问内容。
- 自动演示只有 CRM 线索流程和云犀产品巡演两种模式。
- 重复播放和一键重置不会产生重复客户、任务、合同或通话记录。
- 页面不包含真实联系电话、账号、密码、内网地址或个人隐私。
- 1366px、1024px 和 720px 宽度无页面级横向溢出，弹窗与播放控制条可操作。
- JavaScript 无语法或运行时错误，GitHub Pages 线上返回 HTTP 200。
