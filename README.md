# CRM 与云犀独立教学演示

面向运营商政企销售课堂的静态网页，包含两个独立教学区，无需账号或后端服务。

- **CRM**：天津市河东区 50 家虚构教学企业，覆盖线索筛选、领取分配、模拟联系、跟进任务、客户商机、报价合同、订单、回款和经营分析。
- **云犀功能演示**：云名片、呼叫控制、AI 数析、AI 助手、AI 助销，使用独立的脱敏样本和本地模拟交互。

## 本地启动

在项目目录启动静态文件服务：

```text
python3 -m http.server 8000
```

打开浏览器访问 [本地教学首页](http://localhost:8000)。页面需读取本目录的 JSON 文件，请通过本地服务或静态托管打开，不要直接双击 HTML 文件。

全部字体、图标、脚本和样本均来自系统或本目录；无外部字体、统计代码、真实拨号、录音上传或在线 AI 请求。

## 自动演示

点击顶部“自动演示”，选择“CRM 线索成交演示”或“云犀五项功能导览”。每套在 1 倍速下约 4 分钟。

- 支持播放／暂停、上一步、下一步、0.75／1／1.5 倍速、重播和退出。
- CRM 按筛选 → 领取 → 联系 → T+2 跟进 → 转客户 → 商机 → 报价 → 合同 → 订单 → 回款 → 赢单 → 作战台讲解。
- 云犀依次演示五项功能。控制条说明当前操作、教学理由和数据变化。
- 回看、重播不撤销已完成操作，也不重复新增成交记录。退出时可选择“保留结果”或“恢复演示前状态”，仅影响当前区域。
- 出现业务状态冲突时演示暂停并显示原因；可退出后处理，再开始演示。

## 保存与独立重置

教学操作保存在当前浏览器的 `localStorage`，刷新后保留；不同浏览器、设备和访问地址之间不自动同步。

| 区域 | 本地存储键 | 顶部重置入口 |
| --- | --- | --- |
| CRM | `crm_operator_state_v4` | 重置 CRM 教学数据 |
| 云犀 | `yunxi_teaching_state_v1` | 重置云犀教学数据 |

重置需确认，只恢复所选区域的初始教学数据，另一区域和其他本地数据保持不变。自动演示期间请先退出，再重置。重置后无法从本页面恢复已清除的操作，请勿输入真实业务信息。

## 数据与教学边界

- 50 条企业记录全部为虚构教学数据，不是实际工商查询结果；企业名与联系人均带“模拟”标识，手机号仅显示脱敏格式。
- 需求、评分、金额、沟通过程、通话文本及 AI 输出均为教学模拟，不代表真实商机、通话、经营业绩或实际产品效果。
- 云犀资料依据列于各功能的“查看教学资料”，展示资料标识与核验日期，不包含需要登录的资料链接或访问凭证。
- 无账号密钥、真实客户联系方式或内部经营数据。两区各自保存、各自演示。

## 课堂与键盘使用

已覆盖 1366×768、1024×768 和 720×900 视口。窄屏导航和宽表格可在各自区域横向滚动，页面主体不横向溢出。

Tab 移动焦点，Enter／空格操作按钮；首个键盘入口可跳到主要内容。弹窗将焦点限制在内部，Esc 关闭并返回触发位置。系统开启减少动态效果时，界面减少过渡动画。

## 验收测试

安装 Python 测试依赖和 Chromium：

```text
python3 -m pip install playwright
python3 -m playwright install chromium
```

运行全量验收：

```text
python3 -m unittest discover -s tests -v
git diff --check
```

测试覆盖数据契约、发布文件隐私扫描、CRM 完整成交流程、金额边界、云犀五项交互、双演示幂等、独立重置、弹窗键盘操作及响应式布局。测试服务器只在本机运行，测试浏览器使用独立临时会话。
