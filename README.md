# 运营商政企 CRM 教学原型

一个无需后端的单页 CRM 演示系统，面向通信运营商政企销售培训场景。

## 使用方式

直接打开 `index.html`，或通过 GitHub Pages 访问。右上角“自动演示”可完整演示：

新设企业发现 → 领取线索 → 首次联系 → 转为客户 → 创建商机 → 二次跟进 → 合同订单 → 回款结单。

自动演示提供暂停、上一步、下一步、倍速、重播和退出控制。业务操作保存在浏览器本地存储中，可通过“重置数据”恢复初始状态。

## 验收测试

安装测试依赖与 Chromium 浏览器：

```text
python3 -m pip install playwright
python3 -m playwright install chromium
```

运行可重复的验收测试：

```text
python3 -m unittest discover -s tests -v
```

## 数据边界

- 企业名称、成立日期、行业和登记地域来自页面中标注的公开来源，核验日期为 2026-07-19。
- 联系人、号码、需求、预算、评分、跟进过程及成交信息均为脱敏模拟，仅用于教学。
- 公开信息可能发生变化，使用前请点击原型中的来源链接复核。
- 本项目不包含任何账号密钥、真实客户联系方式或内部经营数据。

## GitHub Pages

将本目录推送到公开仓库 `crm-operator-demo`，在仓库 Settings → Pages 中选择从 `main` 分支根目录发布即可。
